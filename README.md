# Printed Soul — Backend API

Node.js + Express + TypeScript + MongoDB backend for the Printed Soul Store.

## Setup

```bash
npm install
cp .env.example .env
# .env fill karo apni values se
```

## Run (Development)

```bash
npm run dev
```

## Run (Production / VPS)

```bash
npm run build
npm start
```

## Seed Admin

```bash
npx ts-node src/seedAdmin.ts
```

## Environment Variables

See `.env.example` for all required variables.
